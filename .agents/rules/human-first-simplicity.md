# 极简易用与去 AI 味产品设计准则 (Human-First Simplicity & Anti-AI Design Rule)

本规则为项目最高优先级 UI/UX 与文案准则。所有界面、图标、文案与交互必须符合「打开就会用、说人话、克制干净」的真实工具软件标准（参考系统相册与 Picsew）。

## 1. 文案红线：说人话，严禁造词与伪科技黑话

严禁在界面上使用任何自造营销词、科幻词或底层技术名词：

| ❌ 严禁出现的 AI 味文案 | ✅ 必须使用的直白人话 |
| :--- | :--- |
| 长截图工坊 / 滚动画布工坊 | 长截图 |
| 端侧无损连续拼接 / Neural Engine 毫秒级识别 | 自动拼接长图 |
| 微米级机械棘轮微调 / 接缝对齐能量谱 / NCC 磁吸 | 调整接缝 |
| 极光毛玻璃“隐私刮刮乐” / 机密墨水笔 | 打码 / 模糊 / 马赛克 / 涂黑 |
| 双目无缝对比帘幕 / 亚像素对齐 | 拼接前后对比 |
| 3D 拟物视角展台 / 3D 摄影棚悬浮海报 | 最近保存 / 加手机边框 |
| 灵动监控岛 / 离线渲染内存水位 / 微信防糊哨兵 | （直接删除，严禁向用户展示内存/瓦片等开发参数） |
| 智能断句拆解为 9 宫格连拍 | 切九宫格 |

## 2. 视觉与图标红线：去彩虹化、去玄学符号

1. **禁止彩虹图标墙**：同一个页面严禁同时出现红、橙、黄、绿、青、蓝、紫等多个高饱和彩色图标底框（Icon Pod）。全应用仅使用单一主色调（沉稳蓝灰/系统强调色）配合系统原生的 `.primary` 与 `.secondary` 层级。
2. **只用最直白的常见图标**：
   - 选图拼接：`photo.on.rectangle.angled` 或 `plus.viewfinder`
   - 录屏长截：`record.circle`
   - 网页长截：`safari` 或 `globe`
   - 调整接缝：`arrow.up.and.down` 或 `slider.horizontal.3`
   - 打码遮挡：`eye.slash`
   - 标注批注：`pencil.tip`
   - 切图：`square.grid.2x2` 或 `square.grid.3x3`
   - 严禁使用 `waveform.path.ecg`（心电图）、`cube.transparent`（透明立方体）、`crown.fill`（皇冠）、`sparkles`、`wand.and.stars` 等与截图工具无关的浮夸图标。

## 3. 功能与交互减法：3 秒上手原则

1. **首页只做一件事**：
   - 核心区域就是「选择截图拼接」（大按钮，点开直接选图拼好），辅以「滚动录屏长截」和「网页长截」两个清晰入口。
   - 下方用普通、清爽的网格展示「最近保存」的长图，禁止使用令人眼花缭乱的 3D 旋转木马（Cover Flow）。
2. **编辑器只留高频刚需工具**：
   - 严禁在画布上悬浮显示内存占用（MB）、分辨率、色彩空间、迷你雷达条等干扰视线的 HUD。
   - 底部工具栏只保留 4 个直白功能：**「调接缝」**、**「打码」**、**「标注」**、**「切图」**。
   - 顶部只保留：**「取消」**、**「对比原图」**、**「复制」**、**「保存」**。
